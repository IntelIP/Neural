## Implications: executable protocol after access and rule gates pass

**Finite trial:** select three mutually listed MLB regular-season games and one exact team-win proposition per game. Exclude doubleheaders unless official game identity is verified. Target T−60, T−30 and T−10 minutes: nine paired snapshot sets in one trading day. At each set evaluate hypothetical immediate buys of **10, 100 and 1,000 contracts**. Use the same snapshot for all three sizes; no new market requests per size. Selection uses identity and availability, not favorable observed prices. No orders are submitted.

**Permission:** record applicable agreement/version, permitted source, use, retention/deletion date and visibility before collection. Enforce the narrower granted scope if a vendor approves less than requested. A missing or contradictory permission means `access_unconfirmed` and no retained recording for that venue.

**Contract gate:** same official game ID, teams, selected outcome, scheduled instance/game number, full-game period and extra-innings treatment. Compare exact listed rules for official-game threshold, postponement/resumption, cancellation/forfeit, settlement source and exceptional payout. Preserve URL, retrieved time and source digest. Missing rule coverage is `rules_unknown`; any material difference is `rules_different`. Both reject strict ranking. Do not average away fair-value settlement differences or assume YES on one team equals NO on another in every contingency.

**Capture:** acquire venue snapshots concurrently. Preserve decimal price/quantity, venue IDs, side mapping, raw exchange timestamps and their documented meanings, request send/receive UTC, response duration, state and sequence/reconnect status. Proposed trial thresholds: response duration ≤2 seconds; local receive-time skew between venues ≤1 second; explicitly documented snapshot-as-of age ≤5 seconds. For a stream use a contiguous book plus documented live connection/heartbeat evidence; an old last-change time alone does not make an unchanged healthy book stale. If freshness cannot be established with the venue's semantics, reject `freshness_unknown`. Threshold failures reject `stale_or_skewed`. No forward fill across gaps. Each game must still be pregame and open; stop on ambiguous liveness or delayed/rescheduled identity.

**Book and unit validation:** require positive finite depth and price in the instrument's allowed range; ordered noncrossed levels; known tick, order increment, minimum quantity, payout currency and contract multiplier. Preserve fractional displayed depth. Whole-contract order constraints do not justify truncating the incoming data. Unsupported size/increment rejects `quantity_unsupported`; unknown fill/quantity semantics reject `quantity_unknown`. Missing side, exhausted depth or truncated book rejects that size as `insufficient_depth`; never extrapolate a top quote to all sizes. A smaller size may still qualify.

**Calculation:** sort executable offers for the selected outcome. Consume `x_i = min(available_i, Q − consumed)` until Q is reached. Principal is `Σ(x_i × p_i)` and VWAP is principal/Q. Add current venue trading fees using the exact series, account class, role, event phase, effective date and rounding policy. Public aggregated depth does not reveal individual match fragmentation: if this affects fee rounding, report a defensible interval or reject `fee_precision_unknown`. Funding/subscription costs remain separately labeled; no rebate assumed without eligibility. Total estimated acquisition cost = principal + trading fees; report dollars, per-contract cost and visible slippage versus top ask. This estimates displayed immediate execution, not realized fills, arbitrage profit or backtest queue position.

**Decision output:** one row per snapshot, venue and requested size with eligibility/rejection reason, available quantity, VWAP, fee policy, fee/total interval and timestamps. Rank only strictly compatible qualified pairs with nonoverlapping total-cost intervals. Report ties/uncertain ordering explicitly. Report qualified coverage out of nine paired sets separately from cost advantage; rejected observations never become zeros.

**Predeclared venue decision:** a cost-based preference requires at least six qualified paired sets spanning two games at each requested size, and the same venue must have a strictly lower total-cost interval in every qualified comparison across all three sizes. Any reversal, tie or overlapping interval among otherwise eligible observations means defer; missing the coverage threshold at any size also means defer. Do not change size weights, omit unfavorable qualified snapshots or choose a different primary size after seeing results. Account permissions and usable data remain prerequisites. If this rule defers, the provisional technical-readiness recommendation remains separate from cost evidence. A passing one-day pilot supports only the next bounded adapter decision, not persistent venue superiority.
